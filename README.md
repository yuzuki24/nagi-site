iOS アプリ「凪」の公開ページ。GitHub Pages で配信しています。

| | |
|---|---|
| `index.html` | 紹介ページ。App Store Connect の「マーケティング URL」に使えます |
| `privacy.html` | プライバシーポリシー。「プライバシーポリシー URL」に必須 |
| `support.html` | サポート。「サポート URL」に必須 |
